# TG Unban Bot（Node.js 服务器版）

Telegram 群组自助解封 + 违禁词管理 + AI 情绪监控 + 自动回复机器人。

> **基于原创项目改造**
>
> 本项目基于 **[cmliu/CF-Workers-TGUnbanBot](https://github.com/cmliu/CF-Workers-TGUnbanBot)** 改造而成。
> 原作者：[cmliu](https://github.com/cmliu)
> 原项目是 Cloudflare Workers 单文件部署版本，本项目将其适配到普通服务器（Node.js）运行，
> 并新增了违禁词管理、自动回复、AI 情绪监控、Web 管理面板等功能。
> 在此向原作者致敬，感谢其优秀的开源工作。

### 新增功能
- **违禁词管理**：  
  - 双引号 = 精确匹配，无引号 = 包含匹配
  - 每个词可单独配置处罚方式、时长、警告次数
  - 全局配置：启用/关闭、警告上限、处罚方式（踢出/封禁）、处罚时长
- **AI 情绪监控**（智能辱骂检测）
  - 独立骂人检测：5分钟内3+条攻击性消息自动处理
  - 回复骂人检测：回复链3+条敌意消息双向互怼自动处理
  - 累计警告制度：
    - 第1-2次：群里@用户警告，显示次数和AI原因
    - 第3次：私聊通知管理员 + 群里@所有管理员 + 禁言5分钟
    - 第4次+：踢出 + 封禁 + 拉黑
  - AI攻击等级：0=正常, 1=语气不佳, 2=辱骂攻击, 3=严重威胁
  - 支持识别攻击家人脏话（操你妈/日你妈/他妈的等）

## AI 情绪监控详解

### 触发条件
- 消息包含攻击性词汇（傻逼/垃圾/废物/操你妈/滚/闭嘴等）
- AI 判定 hostility ≥ 2（辱骂攻击或严重威胁）

### 处理流程
| 次数 | 群里行为 | 额外处理 |
|------|---------|---------|
| 第1次 | ⚠️ @用户 警告 1/3 + AI原因 | 无 |
| 第2次 | ⚠️ @用户 警告 2/3 + AI原因 | 无 |
| 第3次 | 🔇 @所有管理员 + 已禁言5分钟 | 私聊通知所有管理员（带消息链接） |
| 第4次+ | 🚫 已封禁踢出+拉黑 | 加入联网黑名单 |
